🆘 安裝卡關？5 大常見問題急救箱

        
      

      

        Q1：我在 LINE 傳「清單」，機器人卻「已讀不回」或回系統罐頭訊息？
        ① 回到 LINE Official Account Manager → 回應設定，確認「自動回應訊息」已關閉、「Webhook」已開啟。

        ② 回到 LINE Developers → Messaging API，確認 Webhook URL 貼的是 .../exec 且 Use webhook 開關是綠色的。

        ③ 確認步驟 3 的 GAS 部署時，「誰可以存取」有選 所有人 (Anyone)（可在步驟 3 按「🧪 測試網址」看到綠色成功頁就代表對了）。
      

      

        Q2：步驟 1 一直說我貼錯 Channel access token？
        LINE Developers 有兩個很像的東西：Basic settings 裡的 Channel secret（32 碼短的）是錯的！要切到旁邊 Messaging API 分頁拉到最最底下，按 Issue 才會出現超過 150 碼的 Channel access token。
      

      

        Q3：步驟 3 按部署時跳出紅字「Google 尚未驗證這個應用程式」？
        這是正常現象（因為這支腳本是你自己建立給自己用的，沒上架商店）。只要點左下角灰色小字 「進階 (Advanced)」 → 點 「前往『未命名專案』（不安全）」 → 點 「允許」 即可。
      

      

        Q4：步驟 4 出現「缺少 workflow 權限」或 HTTP 403 / 404？
        這是步驟 2 產生 GitHub Token 時漏勾了 workflow。回到步驟 2 重新點綠色「一鍵開啟已勾好權限的授權碼頁面」產生新 Token 貼上即可。
      

      

        Q5：安裝中途關掉網頁，或想重來怎麼辦？
        直接重跑一次即可！這支精靈支援重複覆蓋更新，不會把你原本的 GitHub 倉庫弄壞。
