歡迎使用 **COOL-LINE**！這是一個 **0 元、免寫程式、全自動** 的台大 NTU COOL 作業與小考 LINE 提醒助理。
只要把這個資料夾交給你自己的 **Antigravity**，它會檢查你還差哪幾步、一步一步帶你完成所有設定！

---

## 🚀 只要 3 步開始安裝

1. **解壓縮到任意資料夾**（例如：`文件\COOL-LINE安裝包`）。
2. **用 Antigravity 開啟這個資料夾作為工作區（Workspace）**。
   > 若不想切換工作區，也可以在新對話直接輸入：
   > `請讀取 <你的解壓路徑>\.agents\skills\cool-line-installer\SKILL.md 並幫我安裝 COOL-LINE`
3. **在對話框輸入**：「**幫我安裝 COOL-LINE**」，接著照著 Antigravity 的提問回答即可！
   - 遇到 LINE / GitHub / Google **帳號登入與權限確認畫面**時，請由你自己動手點一下登入／允許。
   - 若中途關掉電腦或之前裝到一半卡住了，只要重開對話對它說「**繼續安裝 COOL-LINE**」，它會自動偵測已完成的步驟並從卡住的地方接下去！
